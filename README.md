# AI Image Generator

A Python script that generates high-quality images from text prompts using the Pollinations AI API.

## Features

- Generates 1024x1024 images with 8K resolution enhancement
- Cinematic lighting and highly detailed output
- Automatic prompt enhancement for better quality
- Simple command-line interface

## Requirements

- Python 3.x
- `requests` library

## Installation

```bash
pip install requests
```

## Usage

```bash
python main.py
```

Enter your image prompt when prompted. The generated image will be saved as a JPG file in the current directory.

## Example

```
> a futuristic city at sunset
✅ Success! Image saved as a futuristic city at sunset.jpg
```
